# CrossLoop sleep pictures

Two original monochrome illustrations: **Forest Dawn** and **Quiet Orbit**.
Generated with the built-in image tool for CrossLoop on November 8, 2026.

`Build-Wallpapers.ps1` uses the installed ImageMagick to fit and encode each
source as an uncompressed, one-bit BMP at the exact panel size. It creates
separate X4 Pro (480 x 800) and X3 (528 x 792) packs under `generated`.
This avoids first-use image conversion on the reader. Physical display quality
and sleep timing still require device testing.

Copy the contents of the matching device folder to the SD card. The images
belong in `Pictures/CrossLoop`. Choose one with the sleep image picker.
The firmware update does not automatically install these SD files.
